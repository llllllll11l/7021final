# 種子 13 實驗分析

本頁整理 RTX 5090 上的 Qwen2.5-1.5B-Instruct / GSM8K 實驗結果。CPU 重算已核對資料指紋、兩組選樣、實際預算、5,457 筆保存的預測、結果表與 bootstrap，詳見 [核對紀錄](../results/seed13/reproduction.json)。

## 主結果

| 方法 | 測試正確題數 / 1,319 | 主準確率 | 嚴格格式準確率 | 格式合法率 | 平均生成 token |
| --- | ---: | ---: | ---: | ---: | ---: |
| A · Base | 883 | 66.94% | 11.60% | 16.60% | 182.71 |
| B · Random | 820 | 62.17% | 62.09% | 98.64% | 91.65 |
| C · Moderate | 822 | 62.32% | 62.32% | 99.17% | 89.82 |

兩組 SFT 的主準確率低於原始模型，格式遵循率接近 99%，平均回答長度約減半。驗證集的 A/B/C 準確率分別為 80.20%、72.40%、71.80%。

主準確率在缺少 `####` 時採用預先規定的末行數值回退。A 有 730 道正確題依賴這項回退，因此主準確率與嚴格格式準確率需要分開閱讀。

來源：[測試 CSV](../results/seed13/summary_test.csv)、[驗證 CSV](../results/seed13/summary_validation.csv)。

來源：[comparison_test.json](../results/seed13/comparison_test.json)。
